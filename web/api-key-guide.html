AI API 키 연결 안내

설정 → AI 연결에서 연결 방식을 선택하세요. Claude Code·Codex 로그인 방식은 별도의 API 키 없이 연결된 도구를 사용합니다. API 제공자를 직접 선택한 경우에는 그 제공자의 키를 등록합니다. 받아쓰기·얼굴·목소리 구분은 이 PC에서 처리합니다.

Google Gemini API 키 연결 순서

  1. Google AI Studio의 API 키 페이지를 엽니다.
    아래 단추를 누르면 브라우저에서 열립니다. 구글 계정으로 로그인하세요.
    Google AI Studio 열기 ↗
  2. 처음이면 이용약관에 동의합니다.
    처음 들어가면 약관 동의 창이 뜹니다. 내용을 확인하고 동의하세요.
  3. 'API 키 만들기(Create API key)'를 누릅니다.
    프로젝트를 고르라고 하면 기본으로 나오는 것을 그대로 고르면 됩니다.
  4. 만들어진 키를 복사합니다.
    영문·숫자가 섞인 긴 글자입니다. 나온 그대로 전부 복사하세요. 다른 사람에게 알려 주지 마세요.
  5. 이 프로그램에 붙여 넣습니다.
    설정 → AI 연결에서 제공자를 Google Gemini로 고르고, API 키 칸에 붙여 넣으면 바로 저장됩니다. 모델 칸은 비워 두어도 됩니다.
무료 키를 쓸 때 알아 둘 점
  • 무료로 쓰면 하루·분당 쓸 수 있는 양에 한도가 있습니다. 한도를 넘으면 잠시 뒤 다시 시도하세요.
  • 구글 약관상 무료로 쓸 때는 보낸 내용이 구글 서비스 개선에 쓰일 수 있습니다. 공개되지 않은 회의나 개인정보가 담긴 녹취록이라면 기관에서 승인한 서비스(예: 네이버 Clova Studio 공공)를 쓰세요.
  • 기관 보안 장비 때문에 연결이 막히면(인증서 오류) 정보화 담당자에게 문의하세요.

다른 AI를 쓰는 경우

  • 네이버 Clova Studio (공공) — 기관에서 받은 키를 넣고 제공자를 '네이버 Clova Studio (공공)'으로 고릅니다.
  • Anthropic (Claude) · OpenAI — 각 회사 콘솔에서 받은 키를 넣고 해당 제공자를 고릅니다. (유료)
