음성인식 세부
평소 쓰는 Whisper 모델 폴더를 지정할 수 있습니다. 열 수 없으면 이 프로그램의 기본 모델을 사용합니다. 스레드를 12개로 늘려도 6개 대비 12%밖에 빨라지지 않으므로 기본값(물리 코어 − 2)을 권합니다.
화자 구분
일레븐랩스 키를 넣으면 기록·요약에서 ‘화자 다시 나누기’를 쓸 수 있습니다. 여럿이 빠르게 주고받는 대화도 사람별로 나눠 줍니다. 누르는 회의의 녹음 파일이 일레븐랩스 서버로 전송되고, 이용 요금은 일레븐랩스 계정에 청구됩니다. 키는 이 PC의 data/.env 에만 저장됩니다.
여기 세 항목(얼굴·목소리·사회자 지명)은 새 회의의 기본값입니다. 회의 중이나 끝난 뒤에는 녹취록 위의 ‘화자 구분’ 스위치로 바로 바꿀 수 있습니다.
“○○○ 의원님 나오셔서 … 바랍니다”처럼 발언권을 넘기는 말을 AI가 읽고 다음 목소리에 그 이름을 붙입니다. Codex 로그인(없으면 Claude Code 로그인)을 쓰며, 지명하는 말투가 보이는 문장과 직전 몇 문장만 외부로 전송됩니다.
