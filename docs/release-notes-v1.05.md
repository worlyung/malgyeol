# 말결 1.05

대화를 기록으로 잇다.

## 새로 생긴 기능

- **기록·요약에 공유 메뉴**: 회의를 고른 뒤 **내보내기** 옆의 **공유**를 누르면 네 가지 중에서 고를 수 있습니다.
  - **요약 복사**: AI 요약을 카톡·텔레그램에 붙여넣기 좋은 글로 바꿔 복사합니다. 맨 위에 회의명·일시·장소·참석자를 붙이고 요약의 `##`·`**` 같은 기호는 ■·•로 바꿉니다.
  - **녹취록 전체 복사**: 시각과 화자가 붙은 녹취록 전체를 같은 방식으로 복사합니다.
  - **파일로 보내기**: 녹취록 Word 파일(요약이 있으면 요약 Word 파일도)을 `문서\말결 공유` 폴더에 만들고 그 폴더를 엽니다. 대화창이나 메일에 끌어다 놓으면 됩니다.
  - **메일로 보내기**: 메일 제목과 본문(요약)을 복사하고 첨부할 파일 폴더를 엽니다. 어떤 메일 서비스든 메일 쓰기 창에 붙여넣고 파일을 끌어다 놓으면 됩니다.

## 데이터 안내

- 보내기는 사용자가 직접 합니다. 말결은 붙여넣을 글과 끌어다 놓을 파일만 준비하고 메신저나 메일로 자동 전송하지 않습니다.
- 자동 복사가 막힌 환경에서는 공유할 내용을 창에 띄웁니다. 거기서 Ctrl+C로 복사하세요.

## 다운로드 및 설치

`Malgyeol-1.05-Setup.exe`를 받아 실행하세요. 이전 버전을 쓰고 있다면 같은 설치 폴더를 고르고 **프로그램만 새로 덮어쓰기**를 선택하세요. 기록과 설정, 이미 받아 둔 PC 위스퍼는 그대로 남습니다.

명부·용어집·회의 기록·개인 설정·얼굴/목소리 특징·API 키는 들어 있지 않습니다.
SHA256SUMS.txt의 지문으로 내려받은 파일을 대조할 수 있습니다. 코드 서명은 하지 않았습니다.
