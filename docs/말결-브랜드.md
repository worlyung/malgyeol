# 말결 · 1.00

대화를 기록으로 잇다.

말의 흐름과 뉘앙스를 기록에 남긴다는 의미의 이름입니다. 영문 표기는 MALGYEOL입니다.
말풍선과 세 줄 음성 파형으로 아이콘을 구성했습니다. 주색은 숲 초록 #24664B, 밝은 색은 #F7FAF4입니다.

- `assets/malgyeol-logo.svg`: 편집 가능한 로고
- `assets/malgyeol-logo.png`: 투명 배경 로고
- `assets/brand-icon.svg`: 벡터 아이콘
- `assets/malgyeol.ico`: Windows 바로가기 아이콘, 16~256px 9개 해상도
- `web/favicon.png`: 브라우저 아이콘
- `scripts/make_icon.py`: 이미지 재생성 도구 (Pillow 필요)

실행은 바탕화면의 말결 바로가기 또는 `말결 시작.bat`를 사용합니다.
기존 시작 파일과 데이터 저장 경로는 유지합니다. 버전의 기준은 `app/version.py`입니다.
새 업데이트 정보에는 `product: malgyeol`을 넣어 이전 이름의 1.0.7 배포본이 새 버전으로 안내되지 않도록 했습니다.

설치 EXE는 `말결_1.00_설치.exe`로 배포합니다. 설치 창과 Windows 파일 속성에도 제품 이름과 버전을 표시합니다.
