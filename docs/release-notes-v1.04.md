# 말결 1.04

대화를 기록으로 잇다.

## 바뀐 점

- **녹음 파일의 화자 구분**: 일레븐랩스 키를 넣지 않았다면 녹음 파일을 받아쓸 때 Soniox가 화자까지 함께 나눕니다. 사람이 바뀌는 곳에서 문장을 끊고 '화자 1', '화자 2'처럼 붙입니다. 녹음을 한 번만 보내므로 요금이 더 들지 않습니다.
- **화자 다시 나누기는 일레븐랩스 그대로**: 같은 45분 회의를 사람이 고친 녹취록과 대조했더니 일레븐랩스가 98.3%, Soniox가 90.0% 맞았습니다. 그래서 기록·요약의 **화자 다시 나누기**는 계속 일레븐랩스를 씁니다. 일레븐랩스 키가 있으면 녹음 파일도 예전처럼 받아쓴 뒤 이 버튼으로 나누면 됩니다.
- **설정 → 음성인식에 두 방식 설명**: Soniox는 빠르고 정확하며 실시간 받아쓰기에 강합니다. 설치하자마자 바로 쓸 수 있습니다. PC 위스퍼는 소리가 이 PC 밖으로 나가지 않아 보안이 좋고 인터넷 없이도 됩니다.

## 알려진 한계

- Soniox 화자 구분은 목소리가 비슷한 두 사람을 한 사람으로 합칠 때가 있습니다. 정확해야 하는 회의는 일레븐랩스 키를 넣고 **화자 다시 나누기**를 쓰세요.
- 회의 중 실시간 받아쓰기의 화자 구분은 예전처럼 말결이 스스로 합니다.

## 다운로드 및 설치

`Malgyeol-1.04-Setup.exe`를 받아 실행하세요. 이전 버전을 쓰고 있다면 같은 설치 폴더를 고르고 **프로그램만 새로 덮어쓰기**를 선택하세요. 기록과 설정, 이미 받아 둔 PC 위스퍼는 그대로 남습니다.

명부·용어집·회의 기록·개인 설정·얼굴/목소리 특징·API 키는 들어 있지 않습니다.
SHA256SUMS.txt의 지문으로 내려받은 파일을 대조할 수 있습니다. 코드 서명은 하지 않았습니다.
