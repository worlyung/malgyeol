# 말결 1.01

대화를 기록으로 잇다.

## 새로 생긴 기능

- **회의 폴더 옮기기**: 기록·요약의 회의 목록에서 회의 옆 **폴더** 버튼을 눌러 옮길 폴더를 고릅니다. 회의를 끌어다 폴더 이름에 놓아도 되고, **전체 회의**에 놓으면 폴더에서 뺍니다.
- **화자 다시 나누기 (선택)**: 끝난 회의의 녹음을 일레븐랩스로 보내 화자만 다시 받아 옵니다. 말결이 받아쓴 글자는 그대로 두고, 사람이 바뀌는 지점에서 문장을 나눕니다. 나누기 전 녹취록은 `transcript.before-elevenlabs.json`으로 남습니다.
- **설정 → 화자 구분에 일레븐랩스 API 키 칸**: 키는 설치 폴더의 `data/.env`에만 저장하고 화면에는 가려서 보여 줍니다.

## 데이터 안내

화자 다시 나누기는 누른 회의의 녹음 파일 전체를 일레븐랩스 서버로 전송하며, 이용 요금은 일레븐랩스 계정에 청구됩니다. 키를 넣지 않으면 녹음은 이 PC 밖으로 나가지 않습니다.

## 알려진 한계

- 사람이 바뀌는 경계에서 "그", "근데" 같은 한 단어 문장이 가끔 옆 사람에게 붙습니다.
- 화자 다시 나누기를 되돌리는 버튼은 아직 없습니다. 회의 폴더의 백업 파일로 복구할 수 있습니다.

## 다운로드 및 설치

`Malgyeol-1.01-Setup.exe`를 다운로드해 실행하세요. 1.00을 쓰고 있다면 같은 설치 폴더를 고르고 **프로그램만 새로 덮어쓰기**를 선택하세요. 기록과 설정은 그대로 남습니다.

명부·용어집·회의 기록·개인 설정·얼굴/목소리 특징·API 키는 포함하지 않습니다.
SHA256SUMS.txt의 지문으로 다운로드 파일을 대조할 수 있습니다. 코드 서명은 하지 않았습니다.
