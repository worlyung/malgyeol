# 말결 1.06

대화를 기록으로 잇다.

## 꼭 업데이트하세요

- **소리가 20초 넘게 없으면 받아쓰기가 멈추던 문제를 고쳤습니다.** Soniox는 20초 동안 소리가 오지 않으면 연결을 끊습니다. 특히 **PC 소리(스피커)**로 받아쓸 때는 아무 소리도 나지 않으면 윈도우가 소리를 넘기지 않아 회의 중 쉬는 시간에 받아쓰기가 오류로 멈출 수 있었습니다. 이제 소리가 없을 때도 연결을 유지합니다.
- **연결이 끊겨도 저절로 다시 잇습니다.** 인터넷이 잠깐 끊기거나 한 연결의 최대 시간(5시간)을 넘겨도 받아쓰기가 이어지고, 시간도 그대로 이어 붙입니다. 키 오류나 잔액 부족처럼 다시 이어도 소용없을 때만 멈추고 안내합니다.

## 새로 생긴 기능

- **녹음 파일 넣기 단추**: 받아쓰기 화면의 **받아쓰기 시작** 바로 아래에 있습니다. 파일을 고르면 **소리 가져오기**가 파일로 바뀌고, 회의 제목이 비어 있으면 파일 이름으로 채웁니다.
- **간결 보기**: 노트북처럼 창이 작으면 저절로 켜집니다. 왼쪽 메뉴는 아이콘만 남기고 안내 문구를 숨기며 받아쓰는 동안에는 준비 칸과 회의 도구를 접어 녹취록을 크게 보여 줍니다. 위쪽 **간결 보기** 단추나 **설정 → 화면**에서 항상 켜거나 끌 수 있습니다.
- **자막 창**: 위쪽 **자막 창** 단추를 누르면 말결이 작은 창으로 줄어 다른 창 위에 떠 있고 최근 세 문장과 지금 하는 말만 보여 줍니다. 노트북 한 대로 화상회의를 하면서 받아쓸 때 쓰세요. **크게 보기**를 누르면 원래 크기로 돌아갑니다.
- **화면 색**: **설정 → 화면**에서 컴퓨터 설정 따르기(기본), 밝게, 어둡게(다크 모드) 중에서 고릅니다.

## 바뀐 점

- 처음 열 때 창이 화면보다 크면(노트북) 화면에 맞게 줄입니다.
- 녹음 파일은 원본(m4a 등)이 더 작으면 원본을 그대로 보냅니다. 5분짜리 m4a 기준 9.2MB 대신 1.8MB를 보냅니다. 보내는 동안 진행 안내가 나옵니다.
- Soniox로 받아쓸 때는 시작 문구가 "Soniox 연결 중"으로 나오고 PC 위스퍼에서만 쓰는 칸(성능 선택, 음성인식 세부 설정)은 숨깁니다.

## 다운로드 및 설치

`Malgyeol-1.06-Setup.exe`를 받아 실행하세요. 이전 버전을 쓰고 있다면 같은 설치 폴더를 고르고 **프로그램만 새로 덮어쓰기**를 선택하세요. 기록과 설정, 이미 받아 둔 PC 위스퍼는 그대로 남습니다.
