## 새로 생긴 기능

- **AI 연결 상태 표시**: **설정 → AI 연결**에 지금 연결 상태를 크게 보여 줍니다. 연결되면 "✅ 연결됨 — Claude Code 로그인 · Sonnet"처럼 제공자와 모델이 나옵니다. 연결되지 않으면 이유가 함께 나옵니다.
- **연결 시험 단추**: 누르면 AI에게 아주 짧은 질문을 하나 보내 실제로 답이 오는지 확인하고 걸린 시간을 보여 줍니다. 고른 로그인 도구가 로그인되어 있지 않아 다른 로그인 도구로 연결되면 실제로 연결된 쪽을 알려 줍니다.
- **모델 고르기**: 모델을 목록에서 고릅니다. 목록에 없으면 **직접 입력…**을 고르세요.
  - Claude Code 로그인: Opus(가장 똑똑함) · Sonnet(균형) · Haiku(빠르고 가벼움)
  - Codex 로그인: Codex에 물어 그때그때 최신 목록을 받아 옵니다.
  - Anthropic · OpenAI · Gemini(API 키): 키가 있으면 그 회사에 목록을 물어 받아 오고 받지 못하면 기본 목록을 보여 줍니다.

## 바뀐 점

- 기본 목록에 있던 오래된 모델 이름을 최신으로 바꿨습니다.

## 다운로드 및 설치

`Malgyeol-1.08-Setup.exe`를 받아 실행하세요. 설치하기 전에 **말결을 완전히 닫아 주세요.** 이전 버전을 쓰고 있다면 같은 설치 폴더를 고르고 **프로그램만 새로 덮어쓰기**를 선택하세요. 기록과 설정, 이미 받아 둔 PC 위스퍼는 그대로 남습니다.

명부·용어집·회의 기록·개인 설정·얼굴/목소리 특징·API 키는 들어 있지 않습니다.
SHA256SUMS.txt의 지문으로 내려받은 파일을 대조할 수 있습니다. 코드 서명은 하지 않았습니다.
