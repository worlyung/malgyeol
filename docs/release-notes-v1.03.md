# 말결 1.03

대화를 기록으로 잇다.

## 새로 생긴 기능

- **Soniox로 받아쓰기 (기본)**: 받아쓰기 기본 방식을 Soniox(인터넷)로 바꿨습니다. 같은 45분 내부회의 녹음으로 비교해 보니 PC 위스퍼보다 고유명사와 사투리를 훨씬 잘 받아 적었고 문장 부호도 붙습니다. 회의 중에는 소리를 실시간으로 보내고 녹음 파일은 한 번에 보냅니다. 45분짜리 녹음이 1분이 안 걸립니다.
- **설정 → 음성인식에 Soniox API 키 칸**: 키는 soniox.com에서 발급합니다. 설치 폴더의 `data/.env`에만 저장하고 화면에는 가려서 보여 줍니다.
- **PC 위스퍼는 필요할 때만 설치**: 인터넷이 안 되는 곳이나 녹음을 밖으로 보내면 안 되는 회의에 쓰도록, **설정 → 음성인식 → PC 위스퍼 설치**를 누르면 그때 받습니다(약 3GB). 설치하고 받아쓰기 방식을 **PC 위스퍼**로 고르면 이 PC 안에서만 처리합니다.
- **외부 AI용 요약 프롬프트**: 기록·요약에서 회의를 고르고 **외부 AI용 프롬프트**를 누르면 회의 정보와 녹취록을 담은 요약 요청문이 나옵니다. 복사하거나 TXT로 받아 ChatGPT·Claude·Gemini 같은 서비스에 붙여넣으면 됩니다. 말결에 AI를 연결하지 않아도 쓸 수 있습니다.

## 설치 파일이 가벼워졌습니다

PC 위스퍼 모델과 그래픽카드 부품(합쳐서 약 2.9GB)이 기본 설치에서 빠졌습니다. 설치 파일은 1.9GB에서 약 0.2GB로 줄었습니다.

## 데이터 안내

- Soniox로 받아쓰면 회의 소리가 Soniox 서버로 갑니다. 요금(1시간에 약 0.12달러)은 Soniox 계정에 청구됩니다. 녹음 파일은 받아쓰기가 끝나면 Soniox 서버에서 바로 지웁니다.
- 외부 AI용 프롬프트를 붙여넣으면 회의 정보와 녹취록이 그 AI 서비스로 넘어갑니다. 민감한 내용은 보내기 전에 확인하세요. 녹취록이 길면 서비스의 입력 한도를 넘을 수 있습니다.

## 알려진 한계

- 화자 구분은 예전 그대로 말결이 스스로 합니다. Soniox의 화자 구분은 아직 쓰지 않습니다.
- Soniox 키가 없고 PC 위스퍼도 설치하지 않았다면 받아쓰기를 시작할 수 없습니다. 시작 버튼을 누르면 무엇을 해야 하는지 알려 줍니다.

## 다운로드 및 설치

`Malgyeol-1.03-Setup.exe`를 받아 실행하세요. 1.01 이하를 쓰고 있다면 같은 설치 폴더를 고르고 **프로그램만 새로 덮어쓰기**를 선택하세요. 기록과 설정, 이미 받아 둔 PC 위스퍼는 그대로 남습니다. 예전에 PC 위스퍼로만 받아쓰던 분은 Soniox 키를 넣기 전까지 지금처럼 PC 위스퍼로 받아씁니다.

명부·용어집·회의 기록·개인 설정·얼굴/목소리 특징·API 키는 들어 있지 않습니다.
SHA256SUMS.txt의 지문으로 내려받은 파일을 대조할 수 있습니다. 코드 서명은 하지 않았습니다.
