# 말결 1.00

대화를 기록으로 잇다.

- 새 이름 말결(MALGYEOL), 말풍선·음성 파형 로고와 Windows 아이콘
- 받아쓰기, 기록·요약, 용어집, 설정 화면 개편
- 기록 검색, 편집 저장·취소, 내보내기 및 오류 안내 개선
- 설치 창과 Windows 파일 속성에 1.00 표시
- GitHub Releases를 통한 새 버전 안내

## 다운로드 및 설치

`Malgyeol-1.00-Setup.exe`를 다운로드해 실행하세요. Windows용 Python과 음성인식·얼굴·화자 모델, NVIDIA 런타임을 포함한 설치본입니다.
설치가 끝나면 바탕화면의 말결 바로가기로 시작할 수 있습니다.

명부·용어집·회의 기록·개인 설정·얼굴/목소리 특징·API 키는 포함하지 않습니다.
요약용 AI 도구 로그인 또는 API 연결은 사용자 PC에서 설정해야 합니다.

SHA256SUMS.txt의 지문으로 다운로드 파일을 대조할 수 있습니다. 코드 서명은 하지 않았습니다.
이번 배포의 검증 내용과 범위는 저장소의 docs/말결-1.00-배포.md 및 docs/release-verification.json을 참고하세요.
