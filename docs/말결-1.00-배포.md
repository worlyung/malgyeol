# 말결 1.00 배포

## 설치 파일

GitHub 저장소: https://github.com/worlyung/malgyeol

릴리스: https://github.com/worlyung/malgyeol/releases/tag/v1.00

`말결_1.00_설치.exe`는 Python 실행기, 음성인식·얼굴·화자 모델과 GPU용 런타임을 포함합니다.
사용자의 회의 기록, 명부, 용어집, 얼굴·목소리 특징, 설정과 API 키는 포함하지 않습니다.
원본 MIT 저작권 고지는 설치 폴더의 LICENSE로 배포합니다. Python 및 패키지에 포함된 라이선스 파일도 유지합니다.

## 재현

1. `requirements.txt`를 참고해 빌드용 Python에 의존성과 PyInstaller를 준비합니다.
2. `LT_DATA_DIR`을 개인 자료가 없는 빌드 전용 폴더로 지정합니다. 그 폴더의 models 아래에 배포 모델을 준비합니다.
3. `python -m scripts.build_exe --no-roster`로 빌드합니다.
4. `python -m scripts.audit_release`로 Git 추적 파일과 payload.zip의 민감정보 제외 여부를 확인합니다.
5. 설치 EXE의 SHA-256을 기록하고 GitHub 릴리스에 EXE, SHA256SUMS.txt, latest.json을 함께 올립니다.

이번 제작 환경의 패키지 버전은 runtime-packages.json에 기록합니다. 설치 파일 내부 압축은 LZMA입니다.
공개 저장소는 기존 GitLab 원본의 이력을 가져오지 않은 코드 스냅샷이며, 원저작권 표시는 유지합니다.

## 업데이트

`app/version.py`의 VERSION을 바꿔 빌드합니다. latest.json에는 product를 malgyeol로 지정합니다.
말결은 GitHub Releases의 최신 latest.json을 읽습니다. 원본 LiveCaption의 버전 번호와 비교하지 않습니다.

## 검증 범위

- Python 단위 검사 14건: 통과. AI 호출은 모의 응답으로 검사하며 유료 API를 호출하지 않습니다.
- JavaScript 문법 검사: 통과.
- 설치 파일의 실제 설치·실행 결과는 release-verification.json에 기록합니다.
- 실시간 마이크·PC 소리 녹음, 실제 외부 AI 응답 품질, 다른 PC와 GPU의 동작은 이번 설치 시험 범위에 포함하지 않습니다.
