# 말결 1.02

## 외부 AI용 요약 프롬프트

**기록·요약**에서 회의를 선택하고 **외부 AI용 프롬프트**를 누르면 회의 정보와 녹취록이 포함된 요약 요청문을 확인할 수 있습니다. **프롬프트 복사** 또는 **TXT 받기**로 가져와 ChatGPT·Claude·Gemini 등에 직접 붙여넣으세요. 이 기능은 말결의 AI 연결이나 API 키가 없어도 사용할 수 있습니다.

붙여넣으면 회의 정보와 녹취록이 해당 AI 서비스로 전송됩니다. 민감한 내용은 전송 전에 확인하세요. 긴 녹취록은 서비스의 입력 한도를 넘을 수 있습니다.

## 설치

`Malgyeol-1.02-Setup.exe`를 실행하세요. 기존 설치를 갱신할 때는 같은 폴더를 고르고 **프로그램만 새로 덮어쓰기**를 선택하면 기록과 설정이 유지됩니다.

설치 파일에는 개인 회의 기록, 명부, 용어집, 얼굴·목소리 특징, API 키를 넣지 않습니다.
